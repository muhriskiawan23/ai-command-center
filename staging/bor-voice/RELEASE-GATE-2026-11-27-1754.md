## Release gates
1. Obtain authoritative legacy session closure/usage evidence (or independently documented conservative accounting and verified maximum exposure). Preserve existing record and do not mark zero or reset the ledger based on aggregate screenshots. Provider sideband only replays preceding three seconds, so a late attach cannot guarantee recovery of final events. Escalate provider HTTP 503 and request authoritative usage, termination status and maximum WebRTC billable duration.
2. Enforce verified user identity, atomic global and per-account reservation, one in-flight session, idempotency, server deadline, validated usage, and kill switch. A local 60-second timer or dashboard budget notification is not a provider-guaranteed cap. No new paid sessions until exposure fits the approved budget.
3. Run a bounded authenticated owner pilot: actual bidirectional audio, disconnect/reconnect, session closure, final usage, and cost evidence. Then limited production release with rollback. No claim of passed live E2E before observed results.
